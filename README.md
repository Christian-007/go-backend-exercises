# go-backend-exercises

A personal Go backend practice repository designed for system-style coding interviews and hands-on refreshers.

This repository focuses on building small but realistic backend systems incrementally (CRUD, concurrency, event-driven, infra setup), with Git snapshots that let you start practicing from any stage.

## 🎯 Goals

Practice Go backend coding interviews that involve:

- HTTP APIs
  - CRUD with databases
  - Concurrency & multithreading
  - Event-driven architectures
  - Infrastructure setup (Docker, message brokers)
- Build muscle memory for project setup and evolution
- Keep solutions simple, idiomatic, and interview-ready
